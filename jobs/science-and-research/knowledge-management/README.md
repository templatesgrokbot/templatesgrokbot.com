# Knowledge Management templates for Science and Research

Notes, documents, PDFs and knowledge bases kept in order. 15 Grok Bot templates, 13 of them filed in this folder; the others live under their main field and are linked from here.

|---|---|
| [Antibody Lot Validation Tracker](antibody-lot-validation-tracker.md) | Keeps a validation record for every antibody lot and flags uses that are not validated. |
| [Compile Knowledge](../../it-and-development/knowledge-management/compile-knowledge.md) | Compile durable, non-obvious findings into interlinked markdown knowledge files with an index. |
| [Data Storage and Management Assistant](data-storage-and-management-assistant.md) | Plans and audits lab data storage, security, and retrieval workflows. |
| [Geological Map Update Assistant](geological-map-update-assistant.md) | Keeps your project map current with every new field observation, flagging conflicts for your review. |
| [Geological Report Cross-Reference Check](geological-report-cross-reference-check.md) | Checks every figure, table, citation and coordinate in a geological draft against the data files and reports the breaks. |
| [Knowledge Network Steward](knowledge-network-steward.md) | Turns your notes into an atomic, well-linked knowledge network and closes every task with a validation pass. |
| [Laboratory SOP Manager](laboratory-sop-manager.md) | Creates, reviews, and manages lab SOPs with version control and compliance checks. |
| [Library Subject Guide Refresh](library-subject-guide-refresh.md) | Checks every link and resource in a subject guide, drafts updates, and waits for your approval. |
| [Obsidian Second Brain Maintainer](obsidian-second-brain-maintainer.md) | Ingests sources into a persistent Obsidian wiki, keeps entity and concept pages cross-referenced, and maintains a current synthesis. |
| [Oral History Index Builder](oral-history-index-builder.md) | Indexes interview transcripts with standardized names and flags passages that break consent terms. |
| [PDF Document Analyst](../../legal/knowledge-management/pdf-document-analyst.md) | Answers questions about your PDFs, summarizes them, and extracts specific data with page citations. |
| [Protocol Version Aligner](protocol-version-aligner.md) | Keeps every working file citing the current approved protocol version, and routes procedure changes to the investigator. |
| [Research Repository Upkeep](research-repository-upkeep.md) | Keeps your research repository complete, current and findable with monthly checks and drafts. |
| [SOP Training Record Tracker](sop-training-record-tracker.md) | Watches new SOP versions and drafts training assignments for affected lab staff. |
| [Technology Transfer Gap Assessor](technology-transfer-gap-assessor.md) | Compares transfer documents with receiving site capabilities and closes every gap before approval. |
