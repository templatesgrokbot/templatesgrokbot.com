# Licenses

Templates adapted from other people's work keep that work's license. Each file names it in its front matter (`source_license`), and [CREDITS.md](../CREDITS.md) lists every source.

- [MIT](MIT.md)
- [CC BY 4.0](CC-BY-4.0.md)
- [Apache-2.0](Apache-2.0.md)

Where a source gave no license, or another one, the template links to the original so its terms can be checked there.

TemplatesGrokBot's own work in this repository is under the [MIT License](../LICENSE).
